# K3 Launcher (тестовая сборка)
Сборка: загрузите проект в GitHub, вкладка Actions -> Build APK -> артефакт k3-launcher-debug (app-debug.apk).
Или откройте папку в Android Studio и выберите Build -> Build APK(s).
После установки: выдайте доступ к геолокации и (Настройки -> Уведомления -> Доступ к уведомлениям) для K3 Launcher.
